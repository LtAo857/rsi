### 第一批

- `--benchmark advanced` 提供六类任务：求和、平均、计数、条件求和、加权平均、分组最大总额。
- 修复探针轮换求和、工具输出 JSON 恢复、双文件协作；每次 trial 只测试其中一个。
- 套件随状态持久化，重启自动复用；拒绝在同一实验中更换套件。
- 默认 basic 不变；扩展套件是可选接入，未证明真实模型一定无法满分。
- 新测试包含确定性、任务参考答案独立核对、套件锁定、初始求解器提升空间、正确双文件修复评分。

### 第二批

- 合并初始策略与内核重复附加的 Evidence。
- 所有候选 Python 文件先做语法检查；接口健康检查早于外部模型审查。
- `--cache-baseline` 仅缓存成功完成的初评基线 trial，支持中断重启后复用。
- 缓存键包括版本、套件、种子、命令、超时、Python、内核文件和环境摘要；不落盘环境原文。
- 候选与确认评测不复用缓存。远端模型及任意外部脚本的所有变化无法完整指纹化，严格实验可关闭缓存。
- 新测试验证缓存跨实例复用、编码配置变化失效、确认阶段重新调用、Evidence 仅出现一次及语法拒绝。

### 第三批

- 在候选工作区退出前，归档被拒绝的可变源码、原始提案及 diff。
- 结果记录 coding、proposal_validation、review、candidate_evaluation、confirmation 等阶段。
- 失败归档不跟随软链接，限制每文件 200KB、候选文件合计 2MB，明确记录跳过项与读取错误。
- 新测试复现超预算后保留补丁、超时后保留半成品、审查否决归档、软链接与文件大小限制。
- 基线故障尚未产生候选时，仅保留原有基线日志，不伪造候选快照。
