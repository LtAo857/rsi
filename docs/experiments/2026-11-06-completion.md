# 功能补齐、宿主隔离与真实评测

日期：2026-11-06。工程机制、离线测试、真实模型结果分别记录。未证明的研究结果继续在 README 保留未勾选。

## 本批实现

- 分页 CSV 工具增加 aggregate：只能汇总通过 read_csv 观察到且已完整覆盖的记录，支持精确过滤、count 和 Decimal sum。不能读取未观察页或评分答案；异常偏移不构造巨大索引集合。
- 两类固定分页题可从完整观察重算，标记有证据的算术不一致。其他任务仍使用规则风险诊断，不推断通用语义因果。
- 可选独立失败分析模型，校验动作下标和 SQL 动作引用，输出始终为未验证假设。额外调用沿用模型用量账本和预算，不改变评分。
- 改进提示汇总全部 trial 的失败，保留独立 ID；数据压缩明确标记省略量，完整数据保存在原始审计文件。
- 逐机制消融增加新种子确认：初评通过收益/降本门槛且未观察到退步时才运行；初评与确认均须通过，仍不自动删除或发布。
- 可选 macOS Seatbelt 隔离候选 Python 与修复执行程序；源码只读、网络拒绝、环境清理、子进程继承策略及资源/输出上限。新状态显式启用，探测失败拒绝执行，状态配置锁定并防止旧实例绕过。
- 网络适配器限定为固定 DeepSeek 结构化接口，使用隔离导入，拒绝任意外部命令和 Codex CLI。内核、适配器、Python 运行时仍受信任；不宣称 VM、跨平台隔离或硬内存配额。

固定工具是开发者增加的功能，本批分页得分变化不能记作 Agent 自主发布升级。
