# 轨迹诊断与真实记录回放

本批不调用付费模型，开发对象为固定层的可观察事件诊断。

新增 kernel/diagnostics.py：按轨迹下标关联 SQL / 工具错误、无效动作、SQL 截断、未读
或跳过的分页、无观察作答、运行上限及固定评分拒绝。输出区分 observed 事实与 risk 风险，
不把这些规则描述为已验证的语义因果关系，不猜测错误 SQL 条件或算术原因。

评分保持不变。正确完成但中途出错的任务仍然正确，诊断保留错误记录；分页没读完也可能
已通过别的查询获得答案，不能据此判错。连续读完分页消除提示，跳页后续读到结尾不消除
缺页提示；重新从零完整读取后消除。风险规则仍可能有误报。

DataDesk 评测自动增加逐题 diagnostics 和 diagnostic_summary。失败轨迹原样进入
下一轮证据，包括诊断；成功任务的诊断保留在任务评测中，不额外伪造失败 ID。
缓存指纹包含新诊断代码。diagnose 命令接受 evaluation 包装报告或原始 trial 报告，
仅向 stdout 输出，不改变原文件、历史、当前版本或用量账本。

验证：新增 7 项诊断测试，与 12 项 DataDesk 测试合计 19 项通过，7.315 秒。

回放，以及失败诊断传递到候选提示词。
