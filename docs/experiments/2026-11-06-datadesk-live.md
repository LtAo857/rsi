# DataDesk 真实模型实验

日期：2026-11-06（Asia/Shanghai）。本次调用真实模型，离线测试结果另列。

## 配置与范围

- 开发版本：6db9a87。独立状态：`.rsi-datadesk-live-20261106`，不复用脚本实验历史。
- 套件：DataDesk compact，搜索集每类一题，共 5 题；每任务最多 10 个动作。
- 任务模型：DeepSeek `deepseek-flash`，关闭 thinking，服务端每动作最多输出 1024 tokens。
- 编码：DeepSeek `deepseek-flash`；独立审查：DeepSeek `deepseek-v4-pro`。
  编码与审查关闭 thinking，服务端输出上限 4096 tokens；两者同属 DeepSeek，不宣称异构审查。
- 超时 120 秒；实验轮次采用 2 个配对 trial、独立 worktree、新输入确认。
- 基线调用上限 40、token 阈值 60000；进化轮累计调用上限 180、token 阈值 200000，
  单次已报告 token 阈值 18000。阈值不能撤销服务端已发生的费用。
- 密钥使用环境变量，原始状态、模型日志和凭证不提交。
