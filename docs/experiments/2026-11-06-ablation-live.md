- 工具开发版本：4d59bac；任务模型为已保存的 DeepSeek deepseek-flash，thinking disabled，
  每动作服务端输出上限 1024 tokens，超时 120 秒。
- 复用已完成基线验证的独立状态 `.rsi-datadesk-live-20261106`，当前原版本哈希

- 每变体每种子重新运行基线与变体，交替先后顺序。总计 8 次任务评测，计划 40 个任务。
- 开始前累计账本 202 次调用、93071 tokens。设置累计上限 400 次调用、220000 tokens，

```bash
  examples/ablation-prompts.json --seeds 2 --seed 982451653 --timeout 120 \
  --max-calls 400 --max-tokens 220000 --max-call-tokens 18000 \

```

## 解读边界

这是固定任务和两个输入种子上的任务能力消融，不测试 evolution 的改进能力。
模型采样不由输入种子控制，交替顺序不能消除全部随机波动；token 是接口报告的成本代理，
不是美元账单。即使某个变体未退步，也不能认定该提示普遍无用或自动删除。
