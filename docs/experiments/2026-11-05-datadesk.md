# CSV / SQL 多轮任务链路验证

日期：2026-11-05。本批为功能开发与离线验证，未发起真实付费模型调用。

## 功能

- 固定层提供 list_files、read_file、read_csv、schema、sql 五个工具。
  CSV 正确处理引号、逗号和换行；文本和记录均可分页，结果标明下一页或截断。
- CSV 与 JSON 对象数组导入内存 SQLite，列类型为 TEXT。SQL 仅允许读取、指定函数，
  禁止写入、ATTACH、PRAGMA 和多语句；限制查询 VM 工作量、行数与返回大小。
  Python ≥ 3.11 额外使用 SQLite 原生长度限制。
- Agent 每次生成一个工具动作或最终答案。固定内核执行工具并反馈完整动作历史，允许
  查询错误后修正；最多 10 步，另有上下文和连续重复动作限制。
- 可变 Agent 通过 build_messages(task) 和 parse_action(text) 参与循环。基本任务仍保留
  原有单次调用协议；工具、循环上限与评分由固定层维护。
- 任务生成器覆盖 5 类搜索问题和额外 2 类留出问题；compact 为 5 / 7 题，full 为
  15 / 20 题。套件和规模随实验状态锁定，配对输入一致，确认阶段重新生成数据。
- 新增 evaluate 命令，输出轨迹、步数、停止原因及分数，不加入搜索历史。DataDesk 可
  参与现有初评、复评、版本发布、预算、缓存与审计链路。
- README 重写为当前项目的用途、能力、流程、命令与验证状态说明，移除其他项目的
  名称与对比；维护说明同步指向新的功能清单标题。

## 离线测试结果

第一批新增 9 项测试：全部通过，5.645 秒。
补充 full 规模锁定测试后，10 项全部通过，5.876 秒；此时全量 94 项通过，74.435 秒。
增加缺少模型时初始化前拒绝，以及动作解析测试后，新增 12 项全部通过，6.422 秒。

最终全量：`python -m unittest discover -s tests -v`，96 项全部通过，71.863 秒。
`git diff --check` 通过；README 中其他项目名称与对比已移除，示例参数与 CLI 帮助核对。

关键结果：

- 全部 7 类任务经过真实子进程、工具和固定评分链路。脚本先查询错误字段，再根据错误
  执行正确 SQL，7 / 7 通过，每题 4 步，共计 28 次适配器调用。
- 生成器保留 15 道搜索题、20 道留出题、1 道 smoke 题；固定评分对全部 36 个生成答案
  均判对，数值格式变体通过，多数字歧义答案被拒绝。
- 生命周期测试预设一个提示词修改，初始脚本适配器任务得分为 0，候选得分为 1；
  初评和新输入确认均通过后启用新版本。此修改由测试预先指定，没有自主发现。
- CLI 留出评测复用已保存任务配置，保持搜索历史不变；配置或规模更换要求新状态。
- 调用预算耗尽作为基础设施问题传播，不冒充 Agent 的零分；路径越界、外向软链接、
  SQL 写入、ATTACH、多语句、超长查询执行均被拒绝，后续合法查询仍可运行。

适配器位于 tests/fixtures/datadesk_model.py，是按题目生成 SQL 的确定性脚本，只使用
工具返回值作答，不读取评分答案。上述满分仅验证软件链路和评分，不代表真实模型效果。

## 能力边界

数据为合成商店数据，7 类固定问题，真实模型在 DataDesk 上的效果与多轮改进仍待实验。
固定工具限制不是宿主安全沙箱，候选 Python 与编码工具仍拥有宿主进程的文件访问权限。
多轮任务会增加模型调用；每个动作单独记账，预算是累计用量阈值，不是服务端费用硬上限。
