1. **DataDesk `hard`（SQL + CSV，18/18）**：模型在原有 5 类、留出 2 类及新增 3 类 SQL 题（`net_city_revenue`、`top_profit_product`、`repeat_customer_count`）上全部一次通过，未触发 `sql_error`、`sql_without_schema` 或 `untyped_sql_numeric_risk`。仅代表本批固定合成任务与两个种子，不代表开放 SQL 分析能力。
